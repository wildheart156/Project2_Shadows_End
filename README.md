# Shadow's End — Interactive Murder Mystery

## Project Overview

Shadow's End is an interactive murder mystery website developed for CSC 4370 — Web Programming at Georgia State University.

Players become investigators tasked with solving the mysterious murder of Albert Jenkins, a wealthy businessman and founder of Jenkins Technologies.

Through the website, players can explore the story, investigate suspects, examine evidence, solve an interactive puzzle, and make a final accusation to identify the murderer.

## Storyline

Albert Jenkins invites five guests to his mansion for a private dinner. However, the evening takes a deadly turn when the mansion suddenly loses power.

When the lights return, Albert is discovered murdered inside his private theater.

Each guest has a possible motive, but only one is responsible.

Players must carefully examine the evidence and uncover the truth behind Albert's death.

## Website Pages

### 1. Home — `index.html`
Introduces the murder mystery, provides background information, and allows visitors to begin their investigation.

### 2. Suspects — `suspects.html`
Displays the five suspects involved in the investigation:

- Agnes Jenkins
- Dorothy Moore
- Anna Whitlow
- Bentley Preston
- Jonathan Major

Each suspect has a background and possible motive.

### 3. Evidence — `evidence.html`
Presents clues and evidence that help players understand what happened during the murder.

### 4. Puzzle — `puzzle.html`
Features an interactive torn-letter puzzle. Players must arrange the letter pieces in the correct order to reveal an important clue about the murder.

### 5. Conclusion — `conclusion.html`
Allows players to make their final accusation and discover whether they correctly identified the murderer.

## How to Run the Website

1. Clone or download the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Navigate through the website to investigate the murder.
5. Examine the suspects and evidence.
6. Solve the torn-letter puzzle.
7. Submit your final accusation on the conclusion page.
